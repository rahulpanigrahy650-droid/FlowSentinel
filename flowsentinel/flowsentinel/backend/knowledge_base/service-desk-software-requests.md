# Software Licence and Access Requests

## Process
1. Check whether the application is in the approved software catalogue; if it is, the user can install it from the software portal.
2. For licensed tools such as Figma or Adobe, the user's manager approves the request in the service portal.
3. Once approved, assign the licence in the admin console and notify the user.
4. Software not in the catalogue needs a security review before installation.

## Onboarding requests
New starters need a laptop, accounts, MFA enrolment and group memberships; raise one onboarding request with the start date and manager.

## Service level
Standard requests are completed within three working days.
